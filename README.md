- Dashboard inicial com hero, cronologia e área de documentos.
- Responsivo.

## Importante sobre as credenciais
Esta versão é um protótipo estático. As credenciais são armazenadas em `localStorage` e, portanto, **não são seguras para um site real**.

Para produção, o próximo passo é conectar um backend/autenticação (por exemplo Supabase, Firebase ou outro serviço) e nunca armazenar senhas em texto puro.
